GitHub Repository Dashboard API

Welcome to the API-based Automation Dashboard! This API fetches and stores popular Python GitHub repositories.

Available Endpoints:

GET /api/repos
Get all repositories | Try it
GET /api/repos?language=Python&limit=10
Filter by language and limit results | Try it
GET /api/repos/top?limit=5
Get top repositories by stars | Try it
GET /api/stats
Get database statistics | Try it
POST /api/fetch
Manually trigger data fetch

Query Parameters:

  • language - Filter by programming language
  • limit - Limit number of results (default: all)
  • min_stars - Minimum star count
